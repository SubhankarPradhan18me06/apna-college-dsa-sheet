# Database Workspace - Apna College DSA Sheet

This directory serves as the persistent storage for the **Apna College DSA Sheet** database collections. It contains JSON snapshots of the MongoDB collections used by the application.

## Directory Structure

```text
DB/
├── collections/           # JSON snapshots of MongoDB collections
│   ├── chapters.json      # Structured DSA chapters/topics
│   ├── problems.json      # Individual DSA problems with metadata
│   ├── progress.json      # User progress tracking data
│   └── users.json         # User account information
└── README.md              # This documentation file
```

## How to Export Data

To update these files with the latest data from your live MongoDB database, follow these steps:

1. Open your terminal in the `Backend` directory.
2. Run the following command:
   ```bash
   npm run export
   ```
This script will connect to your database and overwrite the JSON files in the `collections/` folder with the current state.
